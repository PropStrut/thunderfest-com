# Detroit Thunderfest

Archive of the **Spirit of Detroit Thunderfest** website, the event site for the Detroit APBA Gold Cup hydroplane races on the Detroit River (1995-2002). The last event covered was the "Chrysler / Jeep Superstores" Detroit APBA Gold Cup, July 11-14, 2002.

The original site was retired in 2003 and is kept live for historical purposes. The successor site is [Gold-Cup.com](http://Gold-Cup.com).

**Live site:** https://thunderfest.com

## What's here

- 1995-2002 photo gallery (repaired 2026)
- "Fearless" Fred Alter's scrapbook photos
- Gold Cup and Detroit racing history
- *Signal Flag Online* newsletter archive
- Quake On The Lake (2000-2002)
