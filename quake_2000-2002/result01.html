Quake on the Lake - Results 2001

These results & records are not official until approved by the APBA!!

New Records

We had five new records set at "Quake On The Lake" in Waterford Michigan this year:

George Kennedy, Jr set a 1 mile record for T class (1.5 Litre Stock) on Saturday, in Bob Wilson's "Outlaw" at 63.196 mph.

Joe Cheezum set a 1 mile record for Y class (1.0 Litre Mod) on Saturday, in his "Miss Zandy" at 68.210 mph and then upped it on Sunday to 70.085 mph.

Calvin Phipps set a 1 mile record for the National Modified class on Saturday, in Schaller Racing's "Schaller Tool Special" at 98.447 mph.

Jean Theoret set a new 1 mile record on Sunday for the Grand Prix class in his "Casino deMontreal" at 102.099 mph. There was no previous GP record for a 1 mile course, but Jean ran real fast and set it well.

CONGRATULATIONS to all of these people and for those of you who did not come that think they can set the record - it has been proven that records can be set on this course - hope to see you next year!!!
