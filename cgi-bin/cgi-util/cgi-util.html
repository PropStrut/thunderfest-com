The cgi-util library of C source code is a powerful CGI interface for your C programs, providing form field searching, conversion to integer and from radio and checkbox fields. Simple file access allows your CGI's to include HTML from files instead of being all hard-coded.

Using cgi-util in your C programs is easy!

  1. Call the "cgiinit()" function to invoke the setup routines.

  2. Tell the browser what type of information you're sending (usually "text/html", but it can be "image/gif", "audio/wav" or any other MIME type!):

    printf("Content-type: text/html\n\n");

  3. Use the "getentry" family of functions to receive data sent to your CGI from the browser. (Either through <input> fields or "URL-encoded.")

  4. Use the "dump" family of functions to use existing HTML or text files in the resulting page.

A Simple Example:

<html><head><title>example form</title></head>
<body>

<h1 align=center>example form</h1>

<form action="example.cgi" method="post">

Your name: <input type="text" name="Name"> <br>
Your age: <input type="text" name="Age"> <br>

<input type="submit" value="Send"> <br>

</body></html>



/* example.c */

#include <stdio.h>
#include "cgi-util.h"

void main()
{
  int age;
  char name[100];

  cgiinit();
  printf("Content-type: text/html\n\n");

  dump("top.html");

  getentry(name, "Name");
  age = getentryasint("Age");

  printf("<h1>%s is %d years old!</h1>\n", name, age);

  dump("bottom.html");
}

Compiling:

  • UNIX:
    The easiest way to compile your program with cgi-util is to use a "makefile" like this one: makefile example.

    A crude way to link the cgi-util routines is to compile it with your source code:

    gcc example.c cgi-util.c -o example.cgi

    Note: Remember to set the permissions on your CGI so that the web server can execute it (otherwise you'll get a "Forbidden" error):

    chmod 755 example.cgi

  • WINDOWS NT:
    Using your C compiler (like MicroSoft Visual C++), create a new "project" for your CGI program. It should be a console-based program (versus a full-blown Windows program). Add "cgi-util.c" to your project, and it should work. If there are problems, please let me know and I'll try to help. Thanks!

    Note: If you're creating an application which displays non-text data ("Content-type: image/gif", for example), you may need to #include <fcntl.h> and add the line: setmode(fileno(STDOUT), _O_BINARY); to your program.
    From: Paul Williams
